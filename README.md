# QuickNotes App
 
QuickNotes App is a simple note-taking web application built with HTML, CSS, and JavaScript. Users can create notes, categorise them, search through existing notes, and delete notes they no longer need. Notes are stored in localStorage, which means they remain available even after refreshing the browser.
 
## Features
 
- Add notes
- Delete notes
- Search notes
- Categorise notes (Work, Personal, Study)
- Validation for empty notes
- Validation for notes longer than 200 characters
- Local storage persistence
- Responsive design for mobile devices
- Dynamic note counter
